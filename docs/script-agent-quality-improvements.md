# 剧本 Agent 原著核实与自动修订

本次改动直接接入运行时，不改写用户的 Skill 或已有作品。

- 骨架、改编策略、审核子 Agent 在提交前必须成功读取当前工作区；有原著的项目至少成功读取一个原文章节。事件摘要和失败读取不能满足原文检查。关键规则、身份、反转的逐项查证继续由模型按照系统约束执行，读取一章不代表全篇事实已验证。
- 剧本工作区由服务端预载给子 Agent；有原著时允许一次读取工具往返，随后直接输出最终稿。系统不再要求先出草稿再强制重写。
- 运行时规则优先于模板中的反转数量和爆款指标；区分原著事实、改编表达和待核实信息。审核区分事实错误、内部矛盾、结构风险与可选建议，要求引用原句和依据。
- 恢复 Toonflow 的阶段边界：故事骨架生成并审核后等待用户确认，再进入改编策略；取消决策 Agent 的同阶段自动修订与复审指令。
- 保存骨架/策略时记录本轮读取章号、服务端工作区预载状态、单次输出质量规则和保存时间。这是读取记录，不是模型事实正确性的证明。
- 修复只读工具对 `get_planData("scriptAgent")` 的兼容，并明确返回数据库读取错误；事件间使用真实换行。

验证：单元测试检查摘要、空原文和失败原文不能通过读取检查；隔离 PostgreSQL 与本地模拟模型验证未经读取的输出被拦回，原文核实后只生成并保存一次最终稿。没有调用付费模型，也未自动重写用户已有骨架。
